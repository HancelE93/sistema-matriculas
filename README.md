\# 🎓 Sistema de Matrículas



Aplicación web fullstack desarrollada con Spring Boot (backend) y React (frontend) para la gestión de estudiantes, pagos e historial.



\---



\## 🚀 Funcionalidades



\- 🔐 Login básico de acceso al sistema

\- 👨‍🎓 Registro de estudiantes

\- 📋 Listado de estudiantes

\- ✏️ Actualización de datos

\- ❌ Eliminación de estudiantes

\- 💰 Registro de pagos

\- 📊 Historial de pagos por estudiante



\---



\## ⚙️ Lógica del sistema



El sistema incluye reglas de negocio importantes:



\- No se permiten cédulas duplicadas

\- Validación de campos obligatorios

\- No se permiten pagos negativos

\- No se puede pagar más que la deuda

\- La deuda se actualiza automáticamente después de cada pago

\- Manejo de errores con mensajes claros



\---



\## 🛠 Tecnologías utilizadas



\- Backend: Java + Spring Boot

\- Frontend: React + JavaScript

\- Estilos: CSS



\---



\## 🧠 Descripción técnica



El backend utiliza almacenamiento en memoria (sin base de datos) para simular persistencia de información, enfocado en la lógica de negocio y el consumo de API REST.



El frontend consume la API mediante fetch y muestra la información en una interfaz con formularios y modales.
